# Embedded web UI

This directory holds the production build of the browser interface, emitted
by Vite from `../../web` and embedded into the Go binary via `//go:embed`.

It is generated by `make web` (or `npm run build` inside `web/`). The
generated `index.html` and `assets/` files are git-ignored; this file keeps
the directory present so `go:embed` succeeds in a fresh checkout before the
frontend is built.
